> Improve 1% every day, with evidence.

Discipline Console is a personal management dashboard designed to help individuals manage their goals, habits, productivity, learning progress, health, and personal growth in a single platform.

The system is built around the idea that consistent daily actions lead to long-term success. Instead of focusing only on outcomes, Discipline Console emphasizes measurable daily execution and continuous improvement.

---

## 🎯 Purpose

Discipline Console was created to serve as a personal operating system for managing multiple areas of life, including:

- Professional career development
- Academic progress
- Skill improvement
- Health and wellness
- Daily productivity
- Long-term goal achievement

The platform helps users transform goals into actionable tasks and track progress through data-driven metrics.

## 🛠️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/discipline-console.git
```

Navigate to the project folder:

```bash
cd discipline-console
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
